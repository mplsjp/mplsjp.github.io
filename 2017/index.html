MPLS JAPAN Award 2017

2017年度より、MPLSおよび関連技術の発展に貢献した個人を表彰する「MPLS JAPAN Award」を創立いたしました。

MPLS JAPAN Award 2017の受賞者は以下の2名です。 詳細はMPLS JAPAN Award 2017のページをご参照ください。

  • 熊木 健二 (KDDI株式会社)
  • 松嶋 聡 (ソフトバンク株式会社)
